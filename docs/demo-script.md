# Five-minute demonstration

Prepare a successful retained classic sample run before preparing its migration, if showing
output comparison. Keep its run ID. Do not edit source/job configuration after plan creation.
Refresh discovery after source changes. Rehearse output comparison before recording; if it
fails, present the failure evidence honestly instead of substituting configuration checks.

| Time | Demonstration |
|---|---|
| 0:00–0:30 | Explain the gap: workspace-level migration coordination and proof |
| 0:30–1:15 | Overview, inventory, readiness and compatibility evidence |
| 1:15–2:15 | Select classic jobs, inspect libraries, save a wave |
| 2:15–3:15 | Review changes, give one approval, show member progress/candidate links |
| 3:15–4:20 | Start validation; show real checks, run links and output metrics where available |
| 4:20–5:00 | Activity, deployable bundle, addressed IDs and honest remaining gaps |

Serverless startup may exceed the recording window. Prepare a prior verified run and show its
retained evidence with a clear timestamp; do not imply a pre-recorded result completed live.
Avoid displaying authentication screens, tokens, customer data or client workspace details.
